## Описание

Это REST API для трекера полезных привычек, который позволяет:

- Создавать, редактировать и удалять привычки.
- Просматривать публичные привычки других пользователей.
- Получать напоминания о привычках через Telegram-бота.
- Использовать JWT-аутентификацию.
- Получать документацию API через Swagger.

---

## Требования

- Python 3.10+
- Redis (для брокера сообщений Celery)
- Docker (опционально, для Redis)
- Postgres (опционально, можно использовать SQLite)
